# FastAPI + PostgreSQL + Docker + CI

A beginner-friendly FastAPI backend project using PostgreSQL, SQLAlchemy, Docker, Docker Compose, Git, GitHub, and GitHub Actions CI.

## 🚀 Tech Stack

- Python 3.11
- FastAPI
- Uvicorn
- PostgreSQL 16
- SQLAlchemy
- psycopg2
- Docker
- Docker Compose
- Git & GitHub
- GitHub Actions
